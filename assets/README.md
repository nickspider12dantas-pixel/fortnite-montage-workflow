# Montage music asset

When you have a music track whose license permits use in your TikTok montage, add the MP3 as `assets/music.mp3` and enter its title, artist, source, and applicable license terms in `music.json`.

Do not upload a track unless its license allows this use. YouTube Audio Library tracks are documented as copyright-safe for YouTube; check the selected track's terms for use on other platforms before using it on TikTok.
