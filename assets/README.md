# Montage music asset

The GitHub Actions workflow generates an original electronic instrumental at `assets/original_synth.wav` with `scripts/generate_music.py`. It is synthesized from mathematical waveforms using Python's standard library and contains no third-party samples or recordings. This avoids needing a music download or a paid music API.

You can replace this with a third-party track only after checking the specific track's license for TikTok/social-media use. One candidate is [Big Bitty (Techno | Dubstep | EDM | Electronic Music) by firemansuperhero on Pixabay](https://pixabay.com/music/electronic-big-bitty-techno-dubstep-edm-electronic-music-121803/); its page requests credit to FIREMAN. Recheck the current track page and applicable terms before publishing. Official [Pixabay Content License summary](https://pixabay.com/service/license-summary/).

If replacing the generated soundtrack, put the licensed audio in this folder and update `music.json` with the filename, source, license terms, and any required credit.
